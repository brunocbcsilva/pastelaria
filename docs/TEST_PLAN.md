# Plano de Testes da Aplicação Pastelaria

Este documento apresenta um plano de testes para a aplicação Pastelaria, visando cobrir aproximadamente 95% das funcionalidades implementadas. Os testes são organizados por componente/tela e funcionalidade, detalhando o objetivo, os passos, os dados de entrada e o resultado esperado.

| ID  | Componente/Tela     | Funcionalidade                        | Objetivo do Teste                                      | Passos para Execução                                                                 | Dados de Entrada                  | Resultado Esperado                                 |
|-----|---------------------|---------------------------------------|--------------------------------------------------------|--------------------------------------------------------------------------------------|-----------------------------------|----------------------------------------------------|
| T01 | HeaderPage          | Exibição do cabeçalho                 | Verificar se o cabeçalho é exibido corretamente         | Acessar a aplicação                                                                   | -                                 | Cabeçalho visível com o nome da pastelaria         |
| T02 | FormPedidos         | Renderização do formulário            | Verificar se o formulário de pedidos é exibido          | Navegar até a tela de pedidos                                                         | -                                 | Formulário visível                                |
| T03 | FormPedidos         | Validação de campos obrigatórios      | Garantir que campos obrigatórios são validados          | Tentar enviar o formulário vazio                                                      | -                                 | Mensagens de erro para campos obrigatórios         |
| T04 | FormPedidos         | Envio de pedido válido                | Testar envio de pedido com dados válidos                | Preencher todos os campos e enviar                                                    | Dados válidos                     | Pedido enviado com sucesso                         |
| T05 | FormPedidos         | Limpeza do formulário                 | Verificar se o formulário é limpo após envio            | Preencher e enviar o formulário                                                       | Dados válidos                     | Formulário limpo após envio                       |
| T06 | Inputs              | Renderização de campos                | Verificar se todos os campos são exibidos               | Acessar o formulário de pedidos                                                       | -                                 | Todos os campos visíveis                          |
| T07 | Inputs              | Máscara/formatação de campos          | Testar máscaras de campos (ex: telefone, CPF)           | Preencher campos com dados inválidos                                                  | Dados inválidos                   | Máscara aplicada e/ou erro exibido                |
| T08 | Modal               | Exibição do modal                     | Verificar se o modal aparece quando acionado            | Acionar evento que abre o modal                                                       | -                                 | Modal visível                                     |
| T09 | Modal               | Fechamento do modal                   | Verificar se o modal fecha corretamente                 | Clicar no botão de fechar/modal                                                       | -                                 | Modal fechado                                     |
| T10 | MediaList           | Listagem de itens                     | Verificar se a lista de produtos é exibida              | Acessar a tela de listagem                                                            | -                                 | Lista de produtos visível                         |
| T11 | MediaList           | Exibição de imagem e descrição        | Garantir que cada item exibe imagem e descrição         | Visualizar itens na lista                                                             | -                                 | Imagem e descrição visíveis para cada item         |
| T12 | App.vue             | Navegação entre componentes           | Testar navegação entre telas/componentes                | Navegar entre as telas principais                                                     | -                                 | Componentes/telas trocam corretamente             |
| T13 | main.js             | Inicialização da aplicação            | Garantir que a aplicação inicializa sem erros           | Iniciar a aplicação                                                                   | -                                 | Aplicação carrega sem erros                       |
| T14 | store.js            | Gerenciamento de estado               | Testar se o estado global é atualizado corretamente     | Realizar ações que alteram o estado (ex: novo pedido)                                 | Dados de teste                    | Estado atualizado conforme esperado               |
| T15 | Geral               | Responsividade                        | Verificar se a aplicação é responsiva                  | Redimensionar a janela/navegar em dispositivos móveis                                 | -                                 | Layout se adapta corretamente                     |
| T16 | Geral               | Acessibilidade                        | Testar acessibilidade básica (teclado, contraste)       | Navegar usando teclado e verificar contraste                                           | -                                 | Navegação e contraste adequados                   |
| T17 | Geral               | Mensagens de erro                     | Verificar exibição de mensagens de erro                 | Forçar erros (ex: campos obrigatórios, falha de envio)                                | Dados inválidos                   | Mensagens de erro exibidas                        |
| T18 | Geral               | Mensagens de sucesso                  | Verificar exibição de mensagens de sucesso              | Realizar ações bem-sucedidas (ex: envio de pedido)                                    | Dados válidos                     | Mensagem de sucesso exibida                       |
| T19 | Geral               | Carregamento de recursos              | Garantir que imagens e assets carregam corretamente     | Navegar pela aplicação                                                                | -                                 | Imagens e assets carregam sem erros               |
| T20 | Geral               | Compatibilidade entre navegadores      | Testar em diferentes navegadores                       | Acessar a aplicação em Chrome, Firefox, Edge, Safari                                  | -                                 | Aplicação funciona em todos os navegadores         |

> **Observação:** Este plano cobre as principais funcionalidades e fluxos da aplicação, incluindo validações, navegação, exibição de dados, responsividade, acessibilidade e mensagens ao usuário. Recomenda-se revisar e atualizar este plano conforme novas funcionalidades forem implementadas.
